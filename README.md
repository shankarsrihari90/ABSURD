# ABSURD

A deliberately unproductive one-page web experience.

## Local preview

Open `index.html` in a modern browser. The page is a static site and uses the Tailwind CDN, so it needs an internet connection for the utility styles and hosted fonts.

## Deploying to Vercel

Import this GitHub repository into Vercel as a static site. No build command or framework preset is required: Vercel will serve `index.html` from the repository root.
